# ⚙️ `actions` — Pipeline Steps

The `actions` package turns every function of the library that takes **one main value and
returns one result** into an `Action` from
[`simplibs-actions`](https://pypi.org/project/simplibs-actions/). An action is the function
with its options bound in advance: constructed once, then called with the one value that
changes — which is what makes steps chainable into a pipeline.

```python
from simplibs.path.actions import CollectFiles, FilterPaths, RebasePath, EnsureParentDir
from simplibs.path.rules import IsDir, HasSuffix, IsHidden

pipeline = (
    IsDir()                                                  # a Rule — becomes a guard step
    >> CollectFiles(include_filter=HasSuffix(".py"))
    >> FilterPaths(rule=~IsHidden())
)

pipeline("~/project")                 # -> [Path(...), Path(...), ...]
await pipeline.acall("~/project")     # the same, off the event loop
```

Actions are **not** exported from `simplibs.path` itself — they are a domain of their own,
imported through `simplibs.path.actions`, which defines `__all__`.

## How an action is built and called

Each action is generated by `create_action` from its function: the function's **first
parameter** (the path, or the root) becomes the *main input*, and **every other parameter**
becomes a keyword-only *constructor option*.

```python
action = RebasePath(source_root="src", target_root="out", new_suffix=".md")   # options
action("src/pkg/a.py")                                                        # main input
# -> <cwd>/out/pkg/a.md
```

* **Constructor options are validated** by the same annotations as the function's
  parameters — a wrong type is a `ValidationError` at construction
  (`CollectFiles(recursive="x")`). A *missing required* option is a plain `TypeError`
  (`RebasePath()`).
* **The main input is validated** when the action is called.
* **Errors raised by the function surface unchanged** — an action adds no layer of its own.
* **The class docstring is the function's docstring**, and `_input_type` / `_output_type`
  expose the annotations for tooling.

## Composition

```python
step_a >> step_b          # run step_b on the result of step_a      (a flat sequence)
step_a & step_b           # run both on the same input              -> (result_a, result_b)
step_a | fallback_step    # run fallback_step if step_a raises
```

A `Rule` is a valid step on either side: `IsDir() >> CollectFiles()` verifies the input,
passes it on **unchanged** (a `guard`), or raises the rule's own failure card. That is why
the predicates have no action of their own.

## Async

All twelve actions are synchronous, so `await action.acall(data)` runs them in a worker
thread (`asyncio.to_thread`) — the right model for blocking file-system calls — and a whole
pipeline can be awaited the same way.

## Two things worth knowing

* **The collectors are really locked.** `CollectFiles` and `CollectDirs` do not have the
  `collect_files` / `collect_dirs` options at all, so `CollectFiles(collect_dirs=True)` is a
  `TypeError`. (They wrap dedicated functions, not a `functools.partial`, which would only
  have changed defaults.)
* **Logging is off for the list-returning actions** (`CollectPaths`, `CollectFiles`,
  `CollectDirs`, `FilterPaths`), because the `log_this` layer would record the whole result
  — potentially tens of thousands of paths — on every call.

## What is not here

* **Predicates** (`is_within`, `is_path_writable`, ...) — a `bool` is not a pipeline value;
  use the matching [rule](README_PATH_RULES.md) as a gate.
* **`iter_paths`** — a generator is consumed once and cannot be logged or re-run by the
  action machinery; pipelines use the list-returning collectors.

# Transformers

### `NormalizePath`

Wraps [`normalize_path`](logic/README_PATH_TRANSFORMERS.md#normalize_path) — makes a
path absolute, `~`-expanded and (by default) symlink-resolved.

**Constructor options:**

* `resolve_symlinks` (*bool*, default `True`): Follow symlinks, or keep them as written.

**Main input:** a path (`PathLike`). **Returns:** `Path`.

**Example usage:**

```python
NormalizePath()("~/project/../project/src")
# -> PosixPath('/home/me/project/src')

pipeline = NormalizePath() >> EnsureDir() >> CollectFiles()    # canonical form first
```

The first step of most path pipelines, so every later step sees one canonical form.

### `NormalizeEntryPath`

Wraps [`normalize_entry_path`](logic/README_PATH_TRANSFORMERS.md#normalize_entry_path) — resolves 
the containing directory while keeping the final name as written. Use it when a pipeline operates 
on the directory entry itself (deleting, moving, renaming or checking a name), rather than 
on the content behind it.

**Constructor options:**

None.

**Main input:** a path (`PathLike`). **Returns:** `Path`.

**Example usage:**

```python
NormalizeEntryPath()("data/link.txt")
# -> /resolved/data/link.txt
# The final name stays "link.txt", even if it is a symlink.

pipeline = NormalizeEntryPath() >> DeleteFile()
```

Unlike `NormalizePath()`, this action does not follow a symlink in the final path component. 
It resolves only the containing directory, so operations on the entry do not accidentally 
target the content behind a final symlink.

### `RebasePath`

Wraps [`rebase_path`](logic/README_PATH_TRANSFORMERS.md#rebase_path) — maps a path from
one root to the same place under another.

**Constructor options:**

* `source_root` (*PathLike*, **required**): The directory the input lives in.
* `target_root` (*PathLike*, **required**): The directory the result should live in.
* `new_suffix` (*str | None*, default `None`): Replace the suffix (`""` removes it).

**Main input:** a path inside `source_root`. **Returns:** `Path`.

**Example usage:**

```python
to_output = RebasePath(source_root="src", target_root="out", new_suffix=".md")
to_output("src/pkg/a.py")                       # -> <cwd>/out/pkg/a.md

write_ready = to_output >> EnsureParentDir()    # also prepare the folder
```

Pure path arithmetic — creates nothing. A path outside `source_root` raises a `ParamError`
when the action runs; the shape of `new_suffix` is also checked then.

### `RelativizePath`

Wraps [`relativize_path`](logic/README_PATH_TRANSFORMERS.md#relativize_path) —
expresses a path relative to a root.

**Constructor options:**

* `root` (*PathLike*, **required**): The directory the result is relative to.

**Main input:** a path inside `root`. **Returns:** `Path`.

**Example usage:**

```python
relative = RelativizePath(root="/home/me/project")
[relative(path).as_posix() for path in collect_files("/home/me/project")]
# -> ['src/a.py', 'src/pkg/b.py', ...]
```

### `ChangeSuffix`

Wraps [`change_suffix`](logic/README_PATH_TRANSFORMERS.md#change_suffix) — replaces,
adds or removes the last suffix.

**Constructor options:**

* `new_suffix` (*str*, **required**): `".md"`, or `""` to remove the suffix.

**Main input:** a path. **Returns:** `Path`.

**Example usage:**

```python
ChangeSuffix(new_suffix=".md")("dir/report.txt")      # -> dir/report.md
ChangeSuffix(new_suffix="")("dir/report.txt")         # -> dir/report
```

Lexical — touches neither the disk nor `~`. A malformed `new_suffix` (`"md"`, `"/x"`) is a
`ParamError` raised when the action runs, not when it is built.

### `MakeUniquePath`

Wraps [`make_unique_path`](logic/README_PATH_TRANSFORMERS.md#make_unique_path) —
returns the path, or a numbered variant (`name (1).ext`) that does not exist yet.

**Constructor options:**

* `max_attempts` (*int*, default `1000`): How many variants to try. Must be positive.

**Main input:** a path. **Returns:** `Path`.

**Example usage:**

```python
step = RebasePath(source_root="src", target_root="out") >> MakeUniquePath()
step("src/report.txt")        # -> out/report (1).txt   if out/report.txt already exists
```

Nothing is created and the name is not reserved — claim it by opening it with mode `"x"`.

# Ensure

These three — together with whatever your own write step does — are the only actions that
change the disk.

### `EnsureDir`

Wraps [`ensure_dir`](logic/README_PATH_ENSURE.md#ensure_dir) — guarantees a directory
(and its parents) exists.

**Constructor options:** none.

**Main input:** a directory path. **Returns:** the normalized `Path`.

**Example usage:**

```python
EnsureDir()("out/reports/2026")       # created with parents; an existing directory is untouched
```

A file in the way raises `StateError`; a refusal by the OS raises `AccessError`.

[▲ Back to top](#-table-of-contents)

---

### `EnsureFile`

Wraps [`ensure_file`](logic/README_PATH_ENSURE.md#ensure_file) — guarantees a file (and
its parent directory) exists.

**Constructor options:**

* `create` (*bool*, default `True`): Create the file when missing. With `False` the action
  is a pure **precondition** — an existing file passes through, a missing one raises
  `NotFoundError`.

**Main input:** a file path. **Returns:** the normalized `Path`.

**Example usage:**

```python
EnsureFile()("logs/app.log")                 # creates logs/ and an empty app.log
must_exist = EnsureFile(create=False)        # "this file must already exist"
pipeline = must_exist >> parse_config        # a plain function is a valid step too
```

An existing file is never truncated.

[▲ Back to top](#-table-of-contents)

---

### `EnsureParentDir`

Wraps [`ensure_parent_dir`](logic/README_PATH_ENSURE.md#ensure_parent_dir) —
guarantees that the folder a path lives in exists, and passes the **path itself** on.

**Constructor options:** none.

**Main input:** the path of a file about to be written. **Returns:** the normalized `Path`
of that file (not its folder).

**Example usage:**

```python
prepare = RebasePath(source_root="src", target_root="out", new_suffix=".md") >> EnsureParentDir()

for source in collect_files("src"):
    target = prepare(source)               # out/pkg/ now exists; the file itself does not
    target.write_text(render(source))
```

# Scanners

All four have `use_logging=False` — see the note above.

### `CollectPaths`

Wraps [`collect_paths`](logic/README_PATH_SCANNERS.md#collect_paths) — collects files
and/or directories of a tree into a sorted list.

**Constructor options** (all optional, all keyword-only):

* `recursive` (*RecursionDepth*, default `True`)
* `include_filter` (*PathPredicate | None*, default `None`)
* `exclude_filter` (*PathPredicate | None*, default `None`)
* `ignore_names` (*Collection[str] | None*, default `DEFAULT_IGNORE_NAMES`)
* `collect_files` (*bool*, default `True`)
* `collect_dirs` (*bool*, default `False`)

**Main input:** the root directory (`PathLike`). **Returns:** `list[Path]`.

**Example usage:**

```python
CollectPaths(collect_dirs=True, recursive=2)("project")
CollectPaths(include_filter=HasSuffix(".py") & ~IsHidden())("project")
```

Options are stored per instance, so two configured instances scan the same root
differently. Both type flags off raises a `ParamError` when the action runs.

### `CollectFiles`

Wraps [`collect_files`](logic/README_PATH_SCANNERS.md#collect_files) — files only.

**Constructor options:** `recursive`, `include_filter`, `exclude_filter`, `ignore_names` —
as in [`CollectPaths`](#collectpaths). There are **no** type flags.

**Main input:** the root directory. **Returns:** `list[Path]`.

**Example usage:**

```python
sources = CollectFiles(include_filter=HasSuffix(".py", ".md"))("project")
```

### `CollectDirs`

Wraps [`collect_dirs`](logic/README_PATH_SCANNERS.md#collect_dirs) — directories only;
the root itself is not included.

**Constructor options:** `recursive`, `include_filter`, `exclude_filter`, `ignore_names` —
as in [`CollectPaths`](#collectpaths). There are **no** type flags.

**Main input:** the root directory. **Returns:** `list[Path]`.

**Example usage:**

```python
folders = CollectDirs(recursive=1)("project")
mirror = [RebasePath(source_root="project", target_root="backup")(d) for d in folders]
```

### `FilterPaths`

Wraps [`filter_paths`](logic/README_PATH_SCANNERS.md#filter_paths) — keeps the paths of
a list that satisfy a `Rule` or callable.

**Constructor options:**

* `rule` (*PathPredicate*, **required**): A `Rule` or `(Path) -> bool` callable.

**Main input:** a collection of paths (list, tuple, set — not a generator).
**Returns:** `list[Path]`, in the original order.

**Example usage:**

```python
CollectFiles() >> FilterPaths(rule=HasSuffix(".py") & ~IsHidden())
FilterPaths(rule=lambda p: p.stat().st_size < 1_000_000)(paths)
```
